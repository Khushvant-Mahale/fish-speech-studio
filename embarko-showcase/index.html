System Design

Fish S2 Pro Engine

Kokoro ONNX Fallback

REST API
Full API for automation
Every studio function exposed as a clean REST endpoint. Build your own workflows, integrate with your pipeline.
POST /api/synthesize_block — Synthesize sentence with S2 Pro emotion tag
POST /api/auto_direct — Auto-detect characters, whispers, screams
POST /api/split_text — Split manuscript into directed sentences
POST /api/export_master — Compile full story into stitched master WAV
POST /api/export_zip — Package sentence audio files into ZIP
GET /api/voices — List active engine voices
POST /api/voices/upload_reference — Upload reference for voice cloning
POST /api/merge_short — Merge consecutive ultra-short fragments
GET /api/config — Manage Colab GPU tunnel & API keys
POST /api/test_remote — Verify remote Colab GPU connection
